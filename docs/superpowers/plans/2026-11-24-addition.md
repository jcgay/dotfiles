# addition Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `addition` command that ranks Claude Code cost, tokens and active time by skill, sub-agent type, Herdr watch step, model or session, and compares two periods.

**Architecture:** One bash script that runs SQL against agentsview's `~/.agentsview/sessions.db`, opened read-only (`file:…?mode=ro`); the Herdr journal is loaded into a TEMP table. `status-jc` appends the session id to its « agent X lancé » journal line.

**Tech Stack:** bash, `/usr/bin/sqlite3` (JSON1, window functions, recursive CTE), node:test for the mod.

**Spec:** `~/docs/superpowers/specs/2026-11-24-addition-design.md`

## Global Constraints

- Never write to `sessions.db`; only TEMP tables.
- Tokens come from `messages.token_usage` (JSON) of assistant rows, deduplicated on `(session_id, claude_message_id)` (one API message is split over several rows, ~7 % duplicates); rows with an empty `claude_message_id` count once each.
- Cost = tokens × `model_pricing` exact match on `messages.model`, microdollars per Mtok; 1h cache writes (`cache_creation.ephemeral_1h_input_tokens`) at `cache_creation_1h_…` when > 0, else at `cache_creation_…`. A model without price counts tokens, cost 0, and is flagged.
- `usage_events` is NOT used (only 158 session-level rows for Claude).
- Commit messages: Conventional Commits, `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- A path typed as first word (`/Users/x/foo bar`) must not become a skill segment: only `^/[a-z][a-z0-9:_-]*` followed by a space or end, no further `/`.
- Sub-agent of a sub-agent (57 sessions): its cost goes to the segment of the top-level Agent call.
- Sub-agent session with no `tool_calls.subagent_session_id` link (~9 %): attributed to its `parent_session_id` top session under `(sous-agent non rattaché)`, never dropped.
- Session with no skill at all: one `(sans skill)` segment.
- Database missing (agentsview not installed): clear error, exit 1.
