# GitHub signature

Applies whenever you write something on GitHub on my behalf: pull request
(title excluded), PR or issue comment, review and review comment, issue,
discussion, release notes — via `gh`, the API or an MCP tool.

End the text with a blank line then `🤖 Jean-Claude` on its own line, so a
reader knows an agent wrote it, not me. It is the very last line; in a PR body
it goes right after the `🤖 Generated with [Claude Code]` line.

Commit messages are git, not GitHub: they keep their `Co-Authored-By` trailer
and don't get this signature.
